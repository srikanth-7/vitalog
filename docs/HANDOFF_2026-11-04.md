## 2. Changes made (all verified: analyze clean, tests pass)

### 2.1 Zip size check (PENDING #24) ✅
- `lib/features/family_health/data/extraction/document_reader.dart`:
  entries are read through `_text()`, which turns an `ArchiveException`
  into `UnsupportedDocument('zip')`. archive ≥ 4.5.2 stops inflating an
  entry at its stated size, so a forged (too small) size fails cleanly
  instead of over-unpacking. The header-sum zip-bomb check stays.
- Test: `test/extraction/document_reader_test.dart` → "an entry that lies
  about its size is refused, not over-unpacked" (forges the size fields).

### 2.2 Temporary "You" name removed (PENDING #25) ✅
- `family_health_repository_impl.dart`: `_withSignedInName` deleted;
  `loadFamilyHealth` no longer renames the "You" member from the Google
  account. `Backend.displayName` is still used for greetings / account card.

### 2.3 Unused Android files deleted (PENDING #26) ✅
- Removed root-level `app/`, `build.gradle`, `settings.gradle`, `gradle/`,
  `gradle.properties` (old Groovy project, Windows JDK path). The real
  Android project is `android/`. Line about it removed from AGENTS.md.

### 2.4 Parser: range by the member's sex (PENDING #18, part) ✅
- `lab_report_parser.dart`: `statusFor(value, range, {Sex? sex})` — for a
  range printed per sex ("M: 13-17 F: 12-15.5", "Men - … Women - …") the
  member's band decides; unknown sex → `needsReview` as before. New
  `LabReportParser.hasSexBands()`.
- `family_health_repository_impl.dart` `_judgeByUsualRange` (static, uses a
  static `_bandJudge` parser): a printed sex-banded range on a result that
  is still `needsReview` is judged with the member's sex. Runs on read,
  edit, move to another member, member edit, restore.
- Limit (`ponytail:` comment there): results already judged aren't
  re-judged if the member's sex changes later (printed H/L flags aren't
  stored separately, so they can't be told apart).
- Not done: age-banded printed ranges — need real sample rows.
- Test: `test/extraction/lab_report_parser_test.dart` ("ranges printed per
  sex …").
